# 2026 Player Stats

## Shiny app for 2026 NFL WR / TE / RB / QB stats.

- Data: nflreadr play-by-play (built by nflfastR) plus official player stats

- Red zone = inside the 25; end zone window = inside the 5

- WR / TE / RB scored in PPR; QB uses official passing fantasy points

- Theme: bslib + Oswald / Silkscreen, with dark-mode toggle
